# ELC Conference MCP server (tickets, attendee perks, partnerships)

One MCP server for ELC Conference 2027: tickets and attendee perks (SimpleShop) and conference partnerships (packages, quotes, offer request).

## Working Discipline
State your assumptions out loud. If the request is ambiguous, ask. If a simpler approach exists, push back. Stop when you are confused, name what is unclear, do not just pick one interpretation and run.

## Goal

Build and deploy a simple MCP server that helps people buy tickets for the ELC Conference (https://elc-conference.io/). The purchase experience must be as seamless as possible — minimal friction, minimal steps, guide the user straight to buying.

## What This Is

A remote MCP server deployed on Cloudflare Workers. Users point their Claude config at the URL and can:
1. Ask about the conference (date, venue, speakers, what to expect)
2. See available tickets with live pricing and availability from SimpleShop API
3. Get a purchase link (with optional discount code for MCP buyers)

No local installation needed — users just add the remote URL to their MCP config.

## Conference data (2027 edition)

Unified 2026-10-01: this repo is THE ELC Conference MCP server (tickets, attendee perks, partnerships).
The partnership tools came from the retired `web/elc-conference-partner-mcp` Worker, names unchanged (its `get_started` folded into `get-started`).

- Attendee facts: `src/conference-data.ts` (sources in its header). The 2027 date is 22 April 2027 (Marian,
  2026-10-08, read from the offer JSON `event.date`); venue, ticket prices and speakers are NOT announced: the
  tools say so. Never type a date or a price in; 2026 figures stay labelled 2026.
- Partnership offer: `src/data/offer-2027.ts`, GENERATED by `node scripts/sync-offer.mjs` from
  `~/ai/business/elcc/data/conference-offer-2027.json` (runs in `build` and `deploy`; CI uses the committed copy).
  After changing the canonical JSON: run the sync, commit the copy, push (CI deploys).
- Live tickets: SimpleShop; `src/tickets.ts` only accepts a non-archived, non-test product named for 2027.
  The 2026 form (qGAKO) is archived.

## Stack

TypeScript, Cloudflare Worker `elc-conference-mcp` (`src/worker.ts`): custom domain `mcp.elc-conference.io`
plus zone routes `elc-conference.io/mcp*` and `www.elc-conference.io/mcp*` (WebMCP bridge + api-catalog read
/mcp there). GET /mcp = HTML docs (canonical www), GET /mcp/info = JSON, POST /mcp = MCP (stateless
`createMcpHandler`). stdio fallback `src/index.ts` (npm package 0.1.1 is stale; no longer in server.json).
Tools: `src/tools/*.ts` (attendee tools one per file, partnership tools in `partnership.ts`), menu in
`src/menu.ts` (single source for get-started, docs, info, llms.txt). Tests: `src/tests` (node:test) +
`test/` (vitest). Rate limiter `OFFER_RATE_LIMITER` (4001); `global_fetch_strictly_public` so the offer POST
reaches www.elc-conference.io/partner/api/offer (elc-conference-ai Worker).
